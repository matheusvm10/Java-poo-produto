# Atividade Produto - Programação Orientada a Objetos (POO)
## Matéria P.A.(Programação de Aplicativos)

Este projeto é uma aplicação Java desenvolvida para demonstrar os conceitos fundamentais da Programação Orientada a Objetos (POO), incluindo encapsulamento, métodos acessores/modificadores e validação de regras de negócio.

## Tecnologias Utilizadas
- **Linguagem:** Java
- **IDE:** IntelliJ IDEA
- **Controlo de Versão:** Git & GitHub

## Funcionalidades
- Encapsulamento dos atributos (`nome`, `preco`, `quantidade`).
- Validação de entrada (garantindo que o preço e a quantidade não assumam valores inválidos).
- Exibição dos dados do produto formatados na consola.

## Como Executar
1. Clona este repositório: https://github.com/matheusvm10/Java-poo-produto.git
2. Abre o projeto no IntelliJ IDEA (ou na tua IDE de preferência).
3. Executa a classe `Main.java`.
